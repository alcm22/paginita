# paginita

Base técnica de la red social paginita. Esta primera fase incluye Next.js, TypeScript, Tailwind, la estructura modular inicial y el sistema visual base. No incluye aún autenticación, base de datos ni funcionalidades sociales.

## Requisitos

- Node.js 20.9 o superior
- pnpm 11 o superior

## Desarrollo

1. Copia `.env.example` como `.env.local` cuando necesites configurar servicios.
2. Ejecuta `pnpm install`.
3. Ejecuta `pnpm dev`.
4. Abre `http://localhost:3000`.

## Comprobaciones

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test:run`
- `pnpm test:e2e:list`
- `pnpm build`
